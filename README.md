### 🪟 Online Windows Simulator

The first prototype is available at:

`projects/online-windows-simulator/index.html`

It currently includes:
- 🖥️ Windows-style desktop
- ⊞ Start menu
- 🪟 Basic simulator window
- 🕐 Live clock
- 📱 Responsive browser layout

More features will be added as development continues.

## 🎯 Goals

TavanTools focuses on creating:

- 🌐 Browser-based applications
- 🖥️ Interactive web environments
- 💬 Communication tools
- 🧪 Experimental projects
- ⚡ Lightweight and easy-to-use experiences

## 🚀 Getting Started

Projects are designed to run directly in a modern web browser whenever possible.

For the Online Windows Simulator, open `projects/online-windows-simulator/index.html` in a browser.
